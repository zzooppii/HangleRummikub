# 사보타지 기본판 규칙과 온라인 정책

2026-09-11 사용자 개발 승인. `SABOTEUR`, `saboteur-base-2025-v1`. 기존 게임의 미확정 사항은 변경하지 않는다.

## CONFIRMED — 기본판

[AMIGO 2025 Version 4.0 공식 설명서](https://blog.amigo-spiele.de/content/ap/rule/04900-GB-AmigoRule.pdf)를 사용한다. 3–10인, 3라운드 개인 금 합계로 승리하며 동률은 공동 승리다.

- 인원 3/4/5/6/7/8/9/10에 대해 사보타지 역할 1/1/2/2/3/3/3/4장, 광부 3/4/4/5/5/6/7/7장을 섞어 각 1장 배분하고 1장은 비공개 제외. 동료 역할도 알 수 없다.
- 라운드마다 40장 길 + 27장 행동을 섞고, 3–5인은 손패 6장, 6–7인은 5장, 8–10인은 4장. 버림은 비공개, 덱 소진 후 다시 섞지 않는다.
- 시작 (0,0), 목표 (8,-2)/(8,0)/(8,2). 카드 사이 7칸, 목표 사이 1칸. 목표는 금 1장과 돌 2장. 90° 회전 불가, 0/180°만 가능.
- 한 턴 한 장으로 길 배치/행동/버리기 후 가능하면 한 장 보충. 의도적 버리기도 가능. 손패가 없는 플레이어는 자동으로 건너뛴다.
- 길은 인접한 모든 공개 길의 입구/벽과 맞아야 하며 출발점에서 실제 통로를 통해 도달할 수 있어야 한다. 막힌 길 내부의 서로 다른 입구는 연결되지 않는다. 낙석으로 끊어진 기존 카드는 남는다.
- 목표에 출발점에서 이어진 길이 닿으면 공개한다. 돌은 가능한 방향으로 맞추되 목표 카드만 불일치 예외가 있다. 금에 도달하면 행동자가 어느 역할이어도 광부 승리. 덱과 전원 손패가 소진되면 사보타지 승리(사보타지가 없으면 보상 없음).
- 곡괭이/등불/수레 고장 중 하나라도 있으면 길 배치 불가. 행동과 버리기는 가능. 타인에게만 고장을 적용하고 같은 종류 중복 불가. 수리는 자신/타인의 대응 고장 1개 제거. 두 종류 수리도 한 종류만 선택하며 예방 사용 불가.
- 낙석은 일반 길 1장만 제거(시작/목표 불가). 지도는 미공개 목표 1장을 본인만 확인한다.
- 라운드 종료에 역할 공개. 광부 승리 시 실제 광부 수만큼 금 카드를 뽑고 도달한 광부부터 역순으로 각 1장 선택. 사보타지가 도달했다면 그 오른쪽 첫 광부부터 시작. 사보타지 승리 시 실제 1/2–3/4명이면 각 4/3/2금. 금 카드는 최종 종료까지 비공개.
- 다음 라운드는 마지막으로 플레이한 사람의 다음 사람이 시작. 역할·목표·행동 덱을 새로 배분하며 모은 금은 유지.

## 카드 구성

공식 총수와 [실물 구성 관찰 기록](https://boardgames.stackexchange.com/questions/13898/how-many-of-each-type-of-path-cards-are-there-in-saboteur)의 도형별 수량을 대조했다. 도형은 N/E/S/W 입구로 표현한다. 연결형 NS 4, NSE 5, NESW 5, ES 4, WS 5, NEW 5, EW 3 = 31장. 막힘형 S/NSW/NESW/ES/WS/W/NS/N/EW 각 1장 = 9장. 막힘형의 입구들은 각각 독립된 막다른 길이다.

행동: 각 장비 고장 3장씩(9), 각 장비 단일 수리 2장씩(6), 각 장비 두 종류 조합 수리 1장씩(3), 지도 6장, 낙석 3장 = 27장. 금: 1금 16장, 2금 8장, 3금 4장 = 28장. 카드마다 opaque ID를 부여하며 새 라운드 길/행동 카드에는 새 ID를 쓴다.

## CONFIRMED — 온라인 정책

- 첫 시작 순서는 서버 난수로 선정한 선공과 입장 순서. 턴 제한 없음. 연결 끊김은 상태를 유지하며 명시적 퇴장은 매치 취소. 종료 방 오프라인 방장 승계는 기존 60초 정책을 따른다.
- 라운드 결과는 전원 확인 후 다음 라운드. 마지막 라운드는 보상 완료 후 최종 점수를 공개한다.
- 자신의 손패·역할·금 카드·지도 관찰만 개인 전송. 타인 손패 장수, 장비, 보드, 덱/버림 장수, 공개 행동과 공개 채팅을 전송한다. 채팅은 240자/2초 간격, 최근 60개. 지도 목표/관찰 내용, 버린 카드, 선택한 금의 값은 행동 기록에 넣지 않는다.
- 지도 결과는 라운드 동안 개인 기록으로 보존하며 재접속 복원. 미공개 목표의 내부 통로/회전은 전송하지 않는다. 공개 전에는 배치 가능 여부가 목표 정체에 의존하지 않는다.
- 공개 목표는 회전 0/180 중 연결 입구를 포함하고 기존 인접 통로와 가장 많이 맞는 방향을 서버가 정한다(동률 0). 이는 실물 카드 방향 맞추기의 결정적 온라인 처리다.
- 사보타지 금 보상은 남은 금 카드에서 정확한 합계의 조합을 서버가 선택한다. 광부의 금 선택은 본인이 수행한다.
