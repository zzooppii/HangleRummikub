# 스파이폴 — SPYFALL

CONFIRMED — 2026-09-11 사용자의 기획 승인 및 “개발 진행해줘”에 따라 구현한다. 기본 질문·만장일치 지목·자발적 장소 추측 규칙은 [참고 규칙서](https://board-game-rules.com/wp-content/uploads/2025/01/spyfall_Official-Rules.pdf)를 따른다. 아래 시간 제한과 연결 처리는 온라인 정책 `spyfall-v1`이다. 다른 게임의 TO_BE_CONFIRMED 항목을 변경하지 않는다.

- 3–8명, 스파이 1명. 방장이 전원 접속 시 시작한다. 준비 버튼은 공통 정책에 따라 없다.
- 설정: 질문 시간 6/8/10분(기본 8), 역할 사용(기본 꺼짐), 장소 묶음 EVERYDAY(일상 12곳)/ALL(전체 24곳, 기본). 장소/스파이/시작 질문자는 서버 주입 난수로 선택한다. 장소 후보는 모두에게 공개한다.
- 역할 확인 15초 후 질문 시간 시작. 비스파이만 선택된 장소 및 역할 사용 시 자기 직업을 받는다. 스파이는 정답 식별자/직업 배정을 받지 않는다.
- 대면 또는 별도 음성 통화로 대화한다. 현재 질문자가 본인·직전 질문자를 제외한 대상을 선택하고, 답변자가 답변 완료를 누르면 다음 질문자가 된다. 웹은 발화 내용 판정/녹음/음성 통신을 하지 않는다.
- 온라인 교착 방지: 질문 상대 선택/답변은 각각 최대 60초. 질문 선택 미응답 시 순환 순서의 다음 참가자로 질문권을 넘기며, 답변 미응답 시 해당 답변자가 다음 질문자가 된다. 전체 질문 시간 만료가 먼저면 최종 지목으로 간다.
- 질문 시간이 흐르는 동안 누구나 타인 1명을 지목할 수 있다. 도중 지목은 각자 1회. 질문 전체 시간과 현재 행동 시간을 함께 멈춘다.
- 지목자 동의는 자동 찬성, 피지목자는 투표권 없음. 다른 참가자는 30초 내 찬성/반대를 비밀 제출한다. 중간 타인 표·제출 여부는 공개하지 않는다. 미응답은 동의하지 않은 것으로 처리한다. 전원 동의 시 스파이 지목이면 시민 승리, 시민 지목이면 스파이 승리. 불일치 시 정확한 남은 질문/행동 시간으로 재개한다.
- 질문 시간이 끝나면 시작 질문자부터 서버가 정한 원형 순서로 최종 지목 기회를 1회씩 제공한다. 후보 선택은 20초, 건너뛰기/미응답이면 다음 지목자. 지목 시 위와 동일한 30초 투표. 전원 기회를 소진해도 유죄 합의가 없으면 스파이 승리. 도중 지목 소진과 최종 지목은 별개다.
- 스파이는 QUESTION/ANSWER에서만 정체를 공개하고 장소 추측 단계에 진입할 수 있다. 공개 후 되돌릴 수 없고 20초 안에 공개 후보 중 하나를 최종 선택한다. 정답이면 스파이 승리, 오답/미응답이면 시민 승리. 멈춘 투표 중/최종 지목 중/잡힌 뒤의 추가 추측은 없다.
- 결과에서 장소·스파이·승리 이유·투표 기록·최종 추측을 공개한다. 누적 점수 없이 한 라운드 단위로 공통 대기실을 통해 재경기한다.
- 일시 연결 끊김은 서버 시간을 유지하고 동일 세션으로 복원한다. 명시적 나가기는 승패 없이 판 취소 및 이탈 처리. 진행 중 신규 참가/관전 없음. 종료 후 방장 연속 오프라인 60초면 접속 참가자로 승계한다. 저장은 기존 in-memory이며 프로세스 재시작 복구는 범위 밖이다.
- 개인 카드 기본 가림, 탭 숨김·연결 변경·단계 변경 시 다시 가림. 장소 제외 메모는 본인 브라우저만 사용하고 판마다 초기화한다.
- 효과음: 카드, 선택, 본인 차례, 지목, 10초 경고, 결과. 사용자 제스처 후 재생, 음량/음소거 저장, 비활성 탭·재접속 과거 효과음 재생 억제. 역할별로 다른 카드 소리는 사용하지 않는다.

## 콘텐츠 및 후속 범위

장소/직업 문구와 일러스트는 자체 제작한다. 내장 음성, 텍스트 전용 진행, 누적 점수, 다중 스파이, 사용자 장소 편집, 관전은 후속 미확정 범위다. 투표 시간과 장소 난이도는 실사용 피드백에 따라 조정할 수 있다.
