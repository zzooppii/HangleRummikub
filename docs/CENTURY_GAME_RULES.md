# 센추리: 향신료의 길 기본판 — CONFIRMED

2026-09-11 사용자가 기본판 개발안의 구현을 승인했다. `century-spice-road-v1`을 사용하며 다른 게임의 미확정 규칙은 변경하지 않는다.

## 기본 규칙

근거: [출판사 공식 규칙](https://cdn.svc.asmodee.net/production-nextmove/uploads/sites/4/2024/06/EN-Century-Spice-Road-Rules_2024_compressed.pdf).

- 2–5인. 상인 카드 43장, 점수 카드 36장. 각자 노랑 2개 생산·2단계 업그레이드 시작 카드. 시장은 상인 6장·점수 5장. 금화·은화는 각각 인원×2개.
- 무작위 선공부터 입장 순서로 순환. 선공 노랑3, 둘째·셋째 노랑4, 넷째·다섯째 노랑3+빨강1.
- 차례당 카드 사용 / 상인 획득 / 휴식 / 점수 카드 획득 중 하나. 생산은 정해진 자원 전부를 받는다. 교환은 같은 비율로 한 번 이상 반복하되 매번 지불 가능해야 한다. 업그레이드는 노랑→빨강→초록→갈색 순서, 0회부터 카드 허용 횟수까지 선택하고 같은 자원의 연속 승급도 가능하다.
- 상인을 가져오려면 왼쪽 카드 각각에 자신이 가진 자원 하나씩을 먼저 놓는다. 획득 카드 위의 자원은 이후 받는다. 획득 카드를 같은 턴에 사용할 수 없다. 시장을 왼쪽으로 당겨 오른쪽을 보충한다. 덱 소진 후에는 있는 카드만 유지한다.
- 휴식은 사용한 카드 전부를 손패로 회수한다. 회수할 카드가 없어도 휴식 가능.
- 점수 카드는 비용을 지불하고 획득한다. 금화는 왼쪽 첫째, 은화는 둘째 카드 보너스. 마지막 금화를 가져가면 남은 은화는 첫째 자리로 옮긴다. 금화3점·은화1점.
- 행동 종료 시 10개 초과 자원은 플레이어가 골라 정확히 초과분만 반환한다. 생산·교환 도중 10개를 넘을 수 있다. 공급은 무제한이며 고정 총량 보존을 적용하지 않는다.
- 2–3인은 점수 카드 6장, 4–5인은 5장 획득 시 마지막 라운드. 선공 직전 자리까지 진행하여 모두 같은 턴 수를 가진 뒤 종료한다. 총점=점수 카드+동전+노랑 외 남은 자원 각1점. 동점은 선공 기준 차례가 더 뒤인 플레이어가 승리.

## 온라인 정책

- 시간 제한·자동 행동 없음. 일시 disconnect/새로고침 시 자리·손패·차례 유지. 명시적 퇴장은 CANCELLED, 승자 없음. 방장 종료 후 60초 오프라인 승계와 같은 방 재시작/게임 교체는 기존 공통 정책.
- 공개: 자원, 사용한 카드, 손패 장수, 획득 점수 카드 장수, 동전 개수, 시장과 카드 위 자원, 덱 잔량, 선공·현재 차례·마지막 라운드·최근 공개 행동.
- 비공개: 상대 손패 ID/내용, 상대 획득 점수 카드·합계, 덱 순서. 자신의 손패·점수 카드는 privateState. 종료 시 점수 항목을 모두 공개한다. 과거 공개 행동의 기억은 제한하지 않는다.
- 선택과 초과 반환은 클라이언트 draft이며 서버에는 한 번의 command로 제출한다. 동일 requestId 재전송은 행동을 반복하지 않는다.
