# 버건디의 성 20주년판

## CONFIRMED

2026-09-12 사용자 후속 요청에 따라 스페셜 에디션에서 2019년 알레아 20주년판으로 변경했다. 포도밭은 제외하고 이 판본에 포함된 문장은 유지한다.

사용자 요청: 2–4인 친구 간 개인전, PC·휴대폰, 방장이 확장과 차례 제한 30/60/90초를 선택한다. 팀전·솔로·장기 이어하기는 제외한다. 시간이 끝나면 남은 주사위는 일꾼 획득에 쓰며 이미 확정한 행동은 유지한다. 미완료 추가 효과는 서버가 합법적인 자동 선택으로 해소한다.

규칙 기준은 [출판사 20주년판 공식 규칙서](https://product-files.ravensburger.cloud/manuals/664462.pdf)다. 사용자가 제공한 [한국어 설명 영상](https://www.youtube.com/watch?v=pEOM8ZD49iw)은 이 환경에서 본문을 가져오지 못했으므로 시청·검증한 자료로 취급하지 않는다. 첨부 사진은 영지 1의 색·주사위 배치와 시각적 방향의 근거다.

- 5시대 × 5라운드. 두 주사위로 타일 획득·영지 배치·상품 판매·일꾼 획득을 수행한다.
- 기본 여섯 색은 성·배·가축·수도원(지식)·은광·건물이다. 같은 색의 빈칸, 맞는 주사위 눈, 기존 타일과 인접 조건을 검증한다. 지식·문장·여관의 명시적 예외는 별도로 적용한다.
- 지역 완성 시 크기 점수 1/3/6/10/15/21/28/36과 시대 보너스 10/8/6/4/2를 즉시 얻는다. 색 전체 완성은 선착순 두 명에게 인원수에 따른 보너스를 지급한다.
- 동물 점수·지역 보너스는 획득 시 기록하며 종료 때 중복 가산하지 않는다. 최종 결과는 게임 중 점수와 남은 상품·은화·일꾼·지식·확장 점수를 구분한다.
- 지식은 20주년판 기준이며 구판 효과를 섞지 않는다. 타일별 효과와 공급 구성은 공유 catalog, 서버 domain과 대응 테스트가 실행 가능한 기준이다.
- 공국·시장·주사위·보관함·자원은 참가자에게 공개한다. 판매한 상품 구성은 소유자만 확인하고 종료 시 공개한다. 미공개 공급 타일·순서는 projection에서 제거한다.

## 구현 자료 검증과 온라인 설정

2019년판 개인전 보드 16종(1–10, 11a–11f)을 원본 사진과 대조했다. 공유 보드 catalog에 각 사진 출처를 기록한다. 무역로 12장의 앞면은 실물 자료와 공식 규칙서의 예시를 대조하며, 판본이 다른 스페셜 에디션 자료를 섞지 않는다.

방장은 공통 영지를 선택한다. 1·2번 영지는 중앙 성에서, 다른 영지는 중앙 성이 있으면 중앙에서, 없으면 보드 순서상 첫 성 칸에서 시작한다. 이는 합법적인 기본 배치이며 각 플레이어의 개별 시작 성 선택 UI는 제공하지 않는다. 시작 성의 효과와 완성 점수는 지급하지 않는다.

국경 초소는 전용 영지 11a–11f에서 사용한다. 세 초소 중 두 곳을 연결하고 세 번째까지 이어 점수를 얻는다. 초소 접점은 보드에 숫자로 표시한다. 스페셜 에디션의 직선 연결 규칙을 사용하지 않는다.

20주년판 지식 6은 은화·일꾼 합계 2개로 번호/검은 시장에서 구매하고 차례당 구매 제한을 공유한다. 종료 동점은 비어 있는 영지 칸이 더 많은 플레이어가 우선한다. 여관을 포함한 지역 크기 점수는 최대 8칸 표를 사용한다.
