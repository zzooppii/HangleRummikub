# CITY 확장판 — CONFIRMED

결정일: 2026-09-10. 사용자가 승인한 건물 분포, 마지막 30종 특수 건물 표, 원작 직업 확장, 방장 설정, 기존 명소와 같은 화풍의 카드 UI를 반영한다.

## 구성과 버전

- 신규 게임은 `city-rules-v3` / `city-cardset-v3` / `city-roles-v2`를 사용한다.
- 일반 건물은 교역 20 / 시정 12 / 수비 11 / 문화 11, 총 54장이다. 기존 CITY의 일반 건물 이름·비용을 유지한다.
- 특수 건물은 30종 각 1장이다. 한 게임에는 14종만 들어가므로 전체 건물 덱은 68장이다. 참가자에게 먼저 4장씩 배분하고 남은 카드로 뽑기 덱을 만든다.
- 일반판: 기본 직업 8개와 추천 특수 건물 14종을 고정한다. 추천 조합은 용의 문, 공장, 유령 지구, 황실 금고, 성채, 연구소, 도서관, 지도실, 채석장, 마법 학교, 대장간, 동상, 도둑 소굴, 소원의 우물이다.
- 확장판: 방장이 1–8번에서 각각 한 직업을 선택하고 9번은 선택적으로 추가한다. 서버가 30종 중 중복 없이 무작위 14종을 선택한다. 선택된 직업과 특수 건물 목록은 모두에게 공개한다.
- 2인 시작에는 9번 직업과 황제를 사용할 수 없으며 왕비는 5인 이상에서 사용한다. 설정은 대기실에서만 방장이 변경할 수 있다. 시작 시 다시 인원 조건을 검증한다.
- CITY의 기존 2–6인 지원, 2·3인당 두 직업, 8채 완성 및 라운드 끝 종료, 동점 공동 순위를 유지한다. 3인의 9번 직업은 선택 사항이다. 원작 2016판의 인원별 종료 건물 수·3인 필수 9직업 규칙으로 바꾸는 작업은 이번 범위에 포함하지 않는다.
- 진행 중인 v1/v2 게임은 저장된 규칙과 카드 수를 그대로 복원한다. 과거 명소 효과를 새 특수 건물 효과로 해석하지 않는다.

## 판정과 카드 이동

- 기본 획득을 마친 뒤 건설·직업 능력·능동 특수 건물 효과를 사용한다. 종류별 수입은 차례 중 한 번 직접 사용하며, 새로 지은 건물을 포함할 시점도 선택할 수 있다.
- 마녀는 기본 획득 후 지목하고 멈춘다. 대상이 기본 획득을 마치면 마녀가 자기 자산으로 대상 직업의 나머지 행동을 한다. 마녀의 첫 차례에는 기본 획득에 영향을 주는 특수 건물만 사용한다.
- 치안판사·협박범의 진짜 표식은 지목자에게만 보인다. 지목된 직업 목록과 암살·도둑·마녀의 대상 직업은 공개하지만, 그 직업을 누가 골랐는지는 원래 공개 시점까지 비공개다.
- 몰수·협박·마법사·예언자·학자·극장·암살된 황제의 왕관 배분은 서버의 대기 선택으로 저장한다. 응답할 플레이어만 해당 선택을 보거나 실행할 수 있다.
- 기본 획득 후보와 학자의 후보는 소유권 구역으로 추적한다. 마법사·첩자가 확인한 다른 손패는 허용된 플레이어에게만 표시한다. 덱 순서와 난수 상태는 전송하지 않는다.
- 골조·묘지는 실제 소유 건물을 희생한다. 도둑 소굴의 카드 지불, 추기경의 정확한 부족분 교환, 공장 할인, 세금과 연금술사 환급을 서버에서 원자적으로 계산한다.
- 건물 파괴 및 지불·교체로 버리는 카드는 뽑기 덱 밑에 둔다. 박물관 아래 카드는 건물에 귀속하며, 건물이 이동하면 함께 이동하고 파괴되면 함께 덱 밑으로 이동한다.
- 마구간과 교역상의 교역 건설, 마법사의 즉시 건설은 일반 건설 횟수를 쓰지 않는다. 항해사는 이러한 예외를 포함해 건설할 수 없다.
- 기념비는 완성 판정에서 2채, 실제 건물 수 표시에서는 1채다. 유령 지구는 종료 점수에서 가장 유리한 한 종류로 계산한다. 다른 종류로 바꾸면 특수 건물 수에서 제외한다.
- 사용자가 지정한 대로 소원의 우물은 자신도 세고, 동상은 왕관 보유 시 5점, 연구소는 카드 1장당 금화 2개다. 비밀 금고는 건설할 수 없으며 종료 시 손패에서 공개해 3점을 더한다.
- 세리는 설정에 포함된 동안 미등장 라운드에도 세금을 적립한다. 예술가 장식은 건물에 귀속하고 비용·점수·8번 직업 지불액에 반영한다.

## 디지털 진행 정책

- 신규 게임의 직업 선택은 기본 20초이며 방장이 대기실에서 10·20·30초 중 정한다. 일반판·확장판 모두 적용하고 시작 후에는 변경할 수 없다. 설정은 모든 참가자에게 공개하며 매 선택 창에 적용한다. 행동 시간은 90초다. 기존 저장 게임에 선택 시간 설정이 없으면 종전 45초를 유지한다. 같은 행동 안의 자원 획득이나 응답으로 마감 시간을 연장하지 않는다.
- 시간 초과의 기본 선택은 첫 카드 유지, 극장 교환 거절, 몰수·협박 공개 거절, 협박 뇌물 지불이다. 예언자는 손패 앞에서 필요한 수를 돌려준다. 필수 마녀 지목·황제 배분은 허용된 첫 대상을 사용한다.
- 기권·연결 복구·세 번째 연속 오프라인 시간 초과는 기존 CITY 정책을 유지한다. 대기 선택이 기권으로 성립하지 않으면 카드 보존을 지키며 해제한다. 9직업 게임이 기권으로 2인이 되면 두 장을 처음 비공개 제거해 2인 선택 흐름을 유지한다.
- 사용자 명령은 인증, 게임/행동 식별자, 현재 응답자, revision, 서버 마감, 카드 소유와 효과별 조건을 검증한다. 실패 시 상태와 난수 체크포인트는 바뀌지 않는다.

## 화면과 이미지

- 대기실에 일반판/확장판 선택과 순번별 직업 선택을 제공한다. 두 모드 모두 직업 선택 시간 10·20·30초를 방장이 설정할 수 있고 기본은 20초다. 모드나 직업을 바꿔도 선택한 시간을 유지한다. 시작 후 조합과 시간은 고정한다.
- 게임 화면은 현재 직업, 공개 표식, 기본 획득, 직업 능력, 특수 건물·대체 건설, 손패, 각 플레이어 도시와 결과 점수를 표시한다. 게임 방법과 이번 게임의 직업·특수 건물 목록은 상단의 작은 버튼으로 열며 팝업 안에서 스크롤한다. 닫기·Escape로 돌아와도 게임 타이머와 직업 선택 상태는 유지된다.
- 선택 단계의 직업 카드·확정 버튼과 행동 단계의 능력·자원 버튼은 유지한다. 행동 단계의 중복 직업 이름·설명 블록만 제거하며, 행동이나 응답이 없는 관전자에게는 빈 패널을 표시하지 않는다.
