# 스플렌더 기본판

상태: CONFIRMED — 2026-09-10 별도 게임 추가 및 그래픽 중심 UI 개발 요청에 따른 v1 구현 기준.
기존 GEM_CARD의 독립 규칙과 카드 데이터는 그대로 유지한다.

- 2–4인 기본판, 개발 카드 90장(40/30/20), 귀족 10종 중 인원+1 공개.
- 보석 5색은 인원별 4/5/7개, 황금은 5개. 처음에는 모두 공용 은행에 있다.
- 각 단계에서 4장 공개. 구매/예약 후 같은 단계 덱에서 같은 자리에 보충한다.
- 턴마다 서로 다른 보석 3개(공용에 3색 미만이면 가능한 색 수), 같은 색 2개(선택 전 4개 이상), 카드 한 장 구매, 카드 한 장 예약 중 하나.
- 황금 직접 가져오기 금지. 공개 카드 또는 단계별 비공개 덱 맨 위를 예약하며 최대 3장. 황금이 있으면 1개를 받으며 없어도 예약 가능.
- 예약 카드는 버릴 수 없고 자기 예약만 구매 가능. 소유자에게만 카드 내용을 전달한다. 공개 시장에서 예약한 카드의 과거 정체를 관찰자가 기억/추론할 수 있다는 사실까지 숨긴다고 주장하지 않는다.
- 각 구매 카드는 해당 색 영구 할인 +1. 할인 후 필요 수량을 해당 보석 또는 황금으로 지불한다. 같은 색 보석이 있어도 황금 대체 허용. 초과 지불 금지.
- 턴 종료 시 보석+황금 합계 10개 이내. 필요한 초과분을 플레이어가 선택해 반환한다. 이번에 얻은 보석도 반환 가능.
- 턴 종료 시 구매 카드의 영구 할인으로 조건을 충족한 귀족을 최대 1명 획득한다. 하나면 자동, 여러 명이면 선택 필수. 보석은 귀족 조건에 포함되지 않는다.
- 카드와 귀족 점수 합이 15 이상이면 해당 라운드를 끝까지 진행한다. 최고점, 동점이면 구매 카드가 더 적은 참가자, 다시 동점이면 공동 승리.

## 온라인 진행 정책

사용자의 개발 진행 요청 범위에서 다음 구현 기본값을 선택했다. 원작 규칙과 구분한다.

- 최초 순서는 주입된 서버 RandomSource로 무작위 결정하고 이후 고정한다. 나이를 수집하지 않는다.
- 턴은 90초. Clock 마감에 도달하면 미확정 선택을 적용하지 않고 턴을 넘긴다.
- 합법적 주 행동이 없을 때만 수동 PASS 가능. 연속 3라운드(인원×3턴) 동안 실제 주 행동이 없으면 INACTIVE로 판을 종료하며 승자를 지정하지 않는다.
- 연결이 끊겨도 보석/카드와 자리 유지, 기존 credential 재접속. 명시적으로 방을 나가면 판 전체 CANCELLED. UI에서 나가기 전에 설명한다.
- 종료 후 방장이 같은 방의 대기실로 돌아가 재경기를 시작할 수 있다. 종료 방장 offline 60초 이후 연결된 참가자에게 승계.
- 보석 선택·지불·반환·귀족 선택은 한 command에서 검증 후 원자적으로 반영한다. 비공개 덱 예약 결과는 commit 이후에만 소유자에게 공개한다.
