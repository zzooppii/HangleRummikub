# 로스트시티 기본판과 온라인 정책

2026-09-11. 사용자 개발 승인에 따른 `lost-cities-base-v1`. 기존 게임의 미확정 규칙은 변경하지 않는다.

## CONFIRMED — 기본 규칙

근거: [Kosmos 공식 설명서 사본, 691820](https://cdn.1j1ju.com/medias/c8/66/47-lost-cities-rulebook.pdf).

- 정확히 2인. 5색마다 숫자 2–10 각 1장, 투자 3장으로 총 60장. 각 라운드에 다시 섞고 손패 8장씩 배분한다.
- 자기 탐험에 카드 1장을 놓거나 같은 색 공용 더미에 버린 뒤 덱 또는 공용 더미 맨 위에서 1장을 가져온다. 방금 버린 카드는 같은 턴에 가져올 수 없다.
- 탐험의 숫자는 반드시 증가한다. 투자 카드는 숫자보다 먼저만 놓는다. 이미 놓인 카드는 회수하거나 이동하지 않는다.
- 덱의 마지막 카드를 가져오면 즉시 정산한다. 추가 차례는 없으며 남은 손패는 점수가 없다. 버림 더미에서 가져오면 덱은 줄지 않는다.
- 미시작 탐험은 0점. 시작한 탐험은 `(숫자 합계 - 20) × (투자 장수 + 1)`이고 음수도 배수가 적용된다. 투자 포함 8장 이상이면 배수 계산 후 20점을 더한다.
- 3라운드의 합산 점수가 높은 사람이 승리한다. 라운드 승수로 판정하지 않는다.

## CONFIRMED — 디지털 기본 정책

개발 승인 범위의 온라인 기본값이며 실물 규칙과 구별한다.

- 첫 선공은 서버 난수로 선정. 이후 누적 점수가 높은 사람이 선공. 동점이면 직전 선공의 반대. 최종 동점은 공동 승리.
- 시간 제한/자동 패스 없음. 연결 끊김은 상태를 유지한다. 명시적 퇴장은 매치 취소이며 승자를 부여하지 않는다. 종료한 방의 오프라인 방장은 60초 후 접속 중인 잔류 참가자에게 승계한다.
- 양쪽 탐험 카드·점수, 버림 더미 맨 위 카드·장수, 덱 잔량, 손패 장수, 공개 행동·라운드 결과를 공개한다. 자신의 손패만 개인별 전송. 상대 손패와 덱 순서·ID, 버림 더미 아래 카드는 전송하지 않는다. 마지막에 뽑은 비공개 카드도 결과에서 노출하지 않는다.
- 놓기/버리기와 가져올 곳을 로컬에서 선택하고 한 턴을 원자적으로 제출한다. 확정 전 변경 가능. 덱 카드 정체는 확정 후에만 공개.
- 양쪽이 결과 확인하면 다음 라운드 배분. 종료 후 공통 같은 방 게임 교체 기능으로 다시 시작. 대기실은 준비 확인 없이 방장 시작.
- 실제 카드마다 새 opaque ID를 생성하고 색·숫자에서 ID를 유추할 수 없게 한다.

## CONFIRMED — 방장 선택형 여섯 탐험 확장

2026-09-11 사용자 요청: 대기실에서 방장이 일반판과 확장판을 선택한다. 근거는 [Kosmos 공식 691821 설명서의 Long Game with Six Expeditions](https://www.thamesandkosmos.com/manuals/full/691821_LC_Card_Game.pdf)다.

- 일반판(BASE)은 기존 5색·60장, 확장판(SIX_EXPEDITIONS)은 보라색 탐험의 숫자 2–10과 투자 3장을 추가한 6색·72장이다.
- 손패는 두 모드 모두 8장. 시작 덱은 각각 44장/56장이다. 턴·투자·점수·8장 보너스·덱 소진·3라운드 누적 규칙은 동일하다.
- 신규 방은 일반판. 대기실에서만 방장이 설정하며 두 사람에게 즉시 표시한다. 시작 시 서버가 모드를 고정하고 다음 라운드와 재접속에서도 유지한다.
- 같은 게임으로 다시 하기에서는 선택을 유지하며, 대기실에서 다시 바꿀 수 있다. 다른 게임으로 전환한 뒤 로스트시티를 새로 선택하면 일반판으로 시작한다.
- 보라색 탐험의 화면 이름은 ‘협곡’이며 자체 제작 일러스트를 사용한다. 테마는 점수 규칙에 영향을 주지 않는다.
