# 늑대의 밤 — WOLF_NIGHT

사용자 요청(2026-09-10): 기존 플랫폼에 ‘늑대의 밤’ 추가. 후속 답변으로 도플갱어를 포함한 기본판 전체 역할을 지정했다. 규칙 버전 `wolf-night-v1`. 다른 게임의 미확정 규칙을 변경하지 않는다.

[배급사 제품 안내](https://beziergames.com/collections/one-night-ultimate-werewolf/products/one-night-ultimate-werewolf), [규칙서 PDF](https://cdn.1j1ju.com/medias/0d/2e/7b-one-night-ultimate-werewolf-rulebook.pdf), [역할별 규칙 전사](https://www.ultraboardgames.com/one-night-ultimate-werewolf/roles.php), [기본 규칙 전사](https://www.ultraboardgames.com/one-night-ultimate-werewolf/game-rules.php)를 교차 참고한다. 원본 이미지·로고·설명문을 복제하지 않는다.

사용자가 후속 메시지로 제공한 준비·밤 순서·낮 투표·승리 조건 요약을 반영했다. 요약에 생략된 최다 1표 이하 무탈락 예외와 선택 능력 생략은 기존 규칙대로 유지한다.

## 기본판 규칙

3–10명, 선택한 역할 카드가 참가자보다 정확히 3장 많아야 한다. 각 참가자 1장, 중앙 3장을 서버에서 무작위 배분한다. 늑대인간 2, 프리메이슨 2, 마을주민 3, 나머지 역할 각 1장을 상한으로 사용한다. 프리메이슨은 반드시 2장, 불면증환자는 강도 또는 말썽쟁이와 함께 선택한다. 기본 자동 구성 외에 방장이 직접 조합할 수 있다.

권장 연령 만 8세 이상, 약 10분. 3인 초보자 자동 구성은 늑대인간 2장과 마을주민·강도·말썽쟁이·주정뱅이 각 1장이다. 4–5인은 마을주민을 한 장씩 추가한다. 6–10인 자동 구성과 직접 역할 선택은 유지한다.

밤 행동은 **처음 받은 역할**로 수행한다. 승패는 **밤이 끝난 뒤 보유한 카드**로 판단한다. 강도로 얻은 역할의 밤 행동을 새로 수행하지 않는다.

| 순서 | 역할 | 행동 |
| --- | --- | --- |
| 1 | 도플갱어 | 다른 사람 1명의 역할을 복사. 예언가·강도·말썽쟁이·주정뱅이는 즉시 행동. 하수인은 즉시 늑대 확인. 늑대·프리메이슨은 해당 시간에 동행. 불면증환자는 맨 마지막에 자기 카드 확인. |
| 2 | 늑대인간 | 서로 확인. 혼자라면 중앙 1장 확인 가능. |
| 3 | 하수인 | 늑대들을 확인. 늑대는 하수인을 알 수 없다. |
| 4 | 프리메이슨 | 서로 확인. |
| 5 | 예언가 | 다른 사람 1장 또는 중앙 2장을 확인하거나 생략. |
| 6 | 강도 | 자신과 다른 사람의 카드를 교환하고 얻은 카드 확인, 또는 생략. |
| 7 | 말썽쟁이 | 자신을 제외한 두 사람 카드 교환, 확인 금지. 생략 가능. |
| 8 | 주정뱅이 | 중앙 1장과 반드시 교환, 확인 금지. |
| 9 | 불면증환자 | 현재 자기 카드 확인. |
| 10 | 도플갱어-불면증환자 | 현재 자기 카드 확인. |

마을주민·사냥꾼·무두장이는 밤 행동이 없다. 복사된 역할은 도플갱어 카드에 귀속되어 카드 교환 뒤에도 유지된다. 중앙에 배분되어 복사하지 않은 도플갱어 카드를 주정뱅이가 가져오면 새 복사 행동 없이 마을팀으로 판정한다. 카드 관찰은 그 시점의 **카드 앞면**을 보여주며, 다른 사람의 도플갱어 복사 내용을 추가 공개하지 않는다.

토론 뒤 자신을 제외한 1명에게 비밀 투표한다. 최다 득표자가 탈락하며 동률은 모두 탈락한다. 최다 득표가 1 이하이면 아무도 탈락하지 않는다. 탈락한 사냥꾼이 투표한 사람도 탈락하며 도플갱어-사냥꾼의 연쇄도 처리한다.

늑대가 한 명 이상 탈락하면 마을팀 승리. 늑대가 없고 아무도 탈락하지 않아도 마을팀 승리. 늑대가 있고 늑대와 무두장이가 아무도 탈락하지 않으면 늑대팀 승리. 늑대가 없으면 하수인은 하수인이 아닌 사람이 탈락할 때 승리한다(무두장이 승리 우선). 무두장이는 자신의 탈락이 승리 조건이며 늑대도 함께 탈락했다면 마을팀과 함께 승리할 수 있다. 생존 여부 자체는 다른 팀원의 승리 조건이 아니다.

## 디지털 진행 정책

역할 확인 15초, 일반 밤 단계 10초(사용자의 진행 시간 단축 요청 반영), 도플갱어 단계 45초. 선택된 공개 카드 구성에 해당하는 단계만 호출하되 중앙 카드로 빠진 역할도 같은 시간을 사용한다. 행동이 끝나도 밤 단계를 조기 종료하지 않는다. 토론 120/180/300초(기본 180), 투표 45초. 토론 중 200자 채팅, 방 전체 최근 100개, 개인 발언 최소 1초 간격. 음성 통화 기능은 포함하지 않는다.

서버 마감 시 선택 행동은 생략한다. 필수 도플갱어 복사·주정뱅이 교환은 주입된 서버 난수로 대신 수행하고 개인 기록에 자동 처리 사실을 남긴다. 미투표는 기권으로 처리한다. 전원 투표하면 결과를 공개할 수 있다. 실물의 사망자 우선 공개와 달리 결과 화면에서는 탈락자와 모든 최종 카드를 함께 공개한다. 낮에는 현재 카드를 다시 확인할 수 없으며 처음 역할과 당시 관찰 기록만 다시 볼 수 있다. 이 자동 처리·기권은 온라인 진행 정책이며 실물 규칙이라고 주장하지 않는다.

연결이 끊겨도 역할과 개인 기록은 유지하며 자동 진행한다. 명시적 방 나가기는 정보·투표의 공정성을 위해 해당 판을 무승부 취소하고 결과 화면으로 이동한다. 종료 후 방장은 같은 방에서 재경기할 수 있다. 종료 중 방장 연속 오프라인 60초 후 연결된 참가자에게 승계한다. 실시간 저장소는 기존 in-memory이며 프로세스 재시작 복구는 제공하지 않는다.

## 남은 범위

확장판 역할은 제외한다. 제공한 영상의 추가 하우스 룰은 확인되지 않았다.
