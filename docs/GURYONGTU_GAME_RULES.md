# 구룡투 기본판과 온라인 정책

2026-09-11. 사용자 요청으로 기본판 2인 온라인 대전을 추가한다. 확장판·AI·관전·공개 배포는 이번 범위 밖이다.

## CONFIRMED

- 2명이 각자 숫자 1–9 타일을 한 장씩 가진다. 홀수는 흰색, 짝수는 검은색이다.
- 공격자가 먼저 타일을 확정한다. 수비자는 그 홀짝만 보고 타일을 확정한다.
- 높은 숫자가 이기되 1은 9를 이긴다. 같은 숫자는 무승부로 승점을 주지 않는다.
- 사용한 타일은 해당 판에서 다시 사용할 수 없다. 타일 숫자는 상대에게 대결 후에도 공개하지 않는다.
- 대결 승자가 다음 공격자다. 무승부면 공격자가 유지된다.
- 한 판은 최대 9대결이다. 승수 차이가 남은 대결 수보다 커 역전·동률이 불가능해지면 조기에 정산한다.
- 판 승리 2회를 먼저 얻으면 매치 승리다.

근거: [제조사 제공 소개](https://v.daum.net/v/WgmANVWASW), [플레이 규칙 설명](https://en.wingboardgame.com/2021/12/how-to-play-showdown-tatics.html), [실물 플레이 설명](https://whatsericplaying.com/2021/05/10/showdown-tactics/). 공식 규칙서 원문 전체는 확보하지 못했으며 다음 항목은 원작 규칙으로 주장하지 않는 온라인 정책이다.

## 확정한 온라인 정책

- **9대결 후 동률은 양쪽 매치 승수를 유지하고 타일을 새로 받아 재경기한다.** 2026-09-11 사용자가 명시적으로 선택했다.
- 각 판의 첫 공격자는 서버 RandomSource로 정한다. 판 결과는 두 사람이 확인한 뒤 다음 판을 시작한다. 새 판은 새 타일 ID를 사용한다.
- 턴 제한시간은 없다. 연결 단절은 제출을 취소하거나 자동으로 타일을 내지 않는다. 복귀하면 같은 playerId로 제출·승수·비공개 손패를 복원한다.
- 명시적 나가기는 기존 2인 게임처럼 매치 취소다. 취소에 승자를 부여하지 않는다. 종료된 방은 기존 방 유지·게임 교체 흐름으로 재시작한다.
- 화면에는 상대 남은 타일의 홀짝 개수, 제출된 타일의 홀짝, 대결별 승패를 표시한다. 본인에게는 자기 사용 타일 숫자도 기록으로 제공한다. 이는 기억을 보조하는 온라인 편의 정책이다.
- 종료·취소·재접속·오류 응답에도 상대 숫자나 상대 타일 ID를 공개하지 않는다. 1 대 9 특수 판정 여부 역시 별도 전달하지 않는다.

## TO_BE_CONFIRMED / 후속 범위
