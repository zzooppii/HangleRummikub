# 아줄 기본판과 온라인 정책

2026-09-11. 사용자가 제안한 게임 시스템을 승인하고 아름다운 UI를 우선한 개발을 요청했다. `azul-base-v1`, 색이 인쇄된 앞면 보드와 2–4인 기본판을 구현한다.

## CONFIRMED — 기본 규칙

[Next Move 공식 규칙서](https://cdn.svc.asmodee.net/production-nextmove/uploads/sites/4/2024/06/EN-Azul-Rules-Next-Move-web.pdf)를 기준으로 한다.

- 색 5종 각 20개, 총 100개의 고유 타일. 2/3/4인 공장 5/7/9개에 각각 무작위 4개 배분.
- 차례마다 공장 하나 또는 가운데의 같은 색 전부를 가져온다. 공장의 나머지는 가운데로 옮긴다. 가운데 첫 선택자는 선 표식을 먼저 바닥에 놓고 다음 라운드 선이 된다.
- 가져온 타일은 준비 줄 하나 또는 전부 바닥에 놓는다. 줄 용량은 1–5개, 같은 색만 가능하며 해당 벽 줄에 이미 놓인 색은 금지. 초과는 바닥. 가득 찬 준비 줄은 새 목적지로 선택하지 않고 바닥 목적지를 사용한다.
- 바닥은 7칸, 감점 1/1/2/2/2/3/3. 이후 타일은 버림 더미로 보낸다. 바닥이 가득 찼을 때도 선 표식 소유권은 보존하며 추가 감점은 없다.
- 공장과 가운데가 비면 모든 개인 보드의 완성 줄을 위에서 아래로 정산한다. 타일 1개를 같은 줄의 지정 색 위치로 이동하고 나머지는 버린다. 미완성 줄은 유지.
- 벽에서 고립된 타일은 1점. 가로와 세로 각각 인접 연결이 있으면 새 타일을 포함한 연결 길이를 합산한다. 대각선은 무관. 바닥 감점은 벽 정산 후 적용하며 점수는 0 미만이 되지 않는다.
- 주머니 소진 시 버림 타일을 섞어 충전한다. 양쪽 모두 부족하면 가능한 수만큼 배분한다.
- 벽 가로줄 완성자가 생긴 라운드의 정산 후 종료. 완성 가로줄당 2점, 세로줄당 7점, 동일 색 5개당 10점. 총점 동률이면 완성 가로줄 수, 그마저 같으면 공동 승리.

## CONFIRMED — 디지털 정책

- 첫 선은 서버 난수로 선택. 각 턴은 서버 Clock 기준 30초. 2026-09-11 사용자가 시간 제한과 시간 초과 시 자동 선택·배치를 승인했다. 서버가 바닥으로 넘치는 타일이 적은 합법적 선택을 우선하고, 동률이면 준비 줄에 놓는 수가 많은 선택, 낮은 줄·공장 순서·색 순서로 결정한다. 자동 선택은 확정 전 브라우저 선택을 참조하지 않는다. 공통 방 정책대로 인원·접속을 확인하고 방장이 준비 확인 없이 시작한다.
- 가져오기와 배치는 하나의 원자적 명령이다. 확정 전 선택은 브라우저에만 존재하며 새로고침 시 폐기된다.
- 라운드 정산과 다음 라운드 배분은 마지막 행동의 서버 transaction에서 자동 처리한다. 최근 라운드 상세를 projection에 남겨 새로고침 후에도 확인할 수 있다. 애니메이션/결과 패널은 서버 진행을 기다리게 하지 않는다.
- 공장·가운데·모든 개인 보드·현재 점수·주머니/버림 더미 총 개수는 공개. 주머니/버림 더미의 타일 ID·색 구성·추첨 순서는 전송하지 않는다.
- 연결이 끊겨도 30초는 계속 흐르며 새로고침/재접속으로 초기화되지 않는다. 명시적 나가기는 매치를 취소하며 승자를 만들지 않는다. 종료 후 같은 방 재시작/게임 교체를 제공한다.
- 종료한 방의 방장이 60초간 오프라인이면 기존 구체 게임 정책과 같이 접속 중인 잔류 참가자에게 방장을 넘긴다. 진행 중 자동 기권은 하지 않는다.
- 공식 스캔/이미지를 복제하지 않고 타일 문양은 직접 작성한 벡터, 배경은 생성한 자체 일러스트를 사용한다.
