# 클루 — 클래식 추리와 온라인 정책

2026-09-11 CONFIRMED. 사용자가 전체 개발과 일러스트 중심 UI를 승인했다. 기존 게임의 TO_BE_CONFIRMED는 변경하지 않는다.

## 기준과 범위

- 기준 규칙: Hasbro Classic Detective Game (1986), https://www.hasbro.com/common/instruct/clueins.pdf . 3–6인, 용의자6/도구6/방9, 주사위1개. 특별 사건 카드와 2인 변형은 포함하지 않는다.
- 인물과 도구 이름은 고전 구성을 따른다. 그림은 새로 제작한다. 지도는 아래 `clue-manor-v1` 오리지널 지도이며 상용 판본의 정확한 칸/출입문 배치를 복제한 것이 아니다. 방9, 복도, 문, 대각선 비밀통로와 방해하는 말의 역할을 유지한다.
- 입장 순으로 스칼렛/머스터드/플럼/그린/화이트/피콕 말을 배정한다. 스칼렛부터 순환한다. 미사용 인물 말도 지도에 존재하고 추리에 포함할 수 있다.
- 무작위로 범주별 카드1장을 봉투에 넣고 나머지18장을 순서대로 분배한다. 카드21개의 실제 인스턴스 ID는 opaque이며 손패와 봉투에 정확히 한 번씩 존재한다.

## 이동과 추리

- 주사위는 서버가 1–6을 생성한다. 온라인 조작 정책으로 눈금 이하의 합법적인 최단 경로 목적지를 선택해 한 번에 이동한다. 이동 후 남은 눈금은 소멸한다. 상하좌우만, 다른 말이 점유한 복도 통과/도착 금지, 같은 칸 재방문 금지, 방에 들어가면 즉시 이동 종료. 같은 이동 중 출발한 방으로 돌아갈 수 없다.
- 문은 방과 지정 복도 칸을 잇는 연결이며 문 그림 자체는 칸이 아니다. 방 진입은 한 걸음이다. 방에는 여러 말이 함께 있을 수 있다.
- 주방↔서재, 온실↔라운지 비밀통로는 차례 시작에 주사위 대신 사용한다.
- 새 방에 도착하면 한 번 추리할 수 있다. 다른 사람의 추리에 의해 실제 다른 방으로 옮겨진 플레이어는 다음 차례에 이동 대신 그 방에서 추리할 수 있다. 추리로 지목된 인물/도구는 해당 방에 남는다.
- 추리는 현재 방+인물+도구. 자기 손패를 포함하는 추리도 합법이다. 이동/추리를 마치면 턴을 종료한다. 이동 가능한 상태에서 차례 시작을 단순 패스할 수 없고, 출구가 모두 막히고 통로도 없으면 턴 종료가 가능하다.
- 질문자의 다음 사람부터 반박한다. 매칭 카드가 없는 사람은 서버가 자동 통과시킨다. 첫 매칭 보유자가 자기 카드 중 한 장을 직접 선택한다. 보유한 매칭 카드가 있는데 없다고 선언할 수 없다.
- 카드 내용은 질문자와 제시자만 확인한다. 공개 기록에는 추리 조합, 통과자, 제시자만 남는다. 첫 반박으로 절차가 종료된다. 아무도 반박하지 못해도 자동 승리가 아니다.

## 최종 지목과 종료

- 자기 차례의 반박 응답 대기 외 단계에서 인물/도구/어느 방이든 최종 지목할 수 있다. 한 게임에 한 번. 추리와 같은 차례에도 가능하다.
- 맞으면 승리하고 봉투와 전체 손패를 공개한다. 틀리면 그 사람만 봉투를 보고 이동·추리·재지목 권한을 잃지만, 반박 카드는 계속 제시한다. 다른 사람이 그 인물을 방으로 옮기는 것도 가능하다. 오답자의 말이 문 앞을 막으면 그 방으로 옮긴다.
- 마지막 활동 플레이어에게 자동 승리를 주지 않는다. 모두 최종 지목에 실패하면 ALL_ELIMINATED로 승자 없이 종료한다.
- 시간 제한 없음. 접속 단절은 차례/응답/카드를 보존하고 재접속을 기다린다. 명시적 퇴장은 CANCELLED로 판을 중단하고 종료 정보를 공개한다. 종료 후 공통 방장 승계/같은 방 게임 선택을 사용한다.

## 비공개 정보와 기록

- 손패는 소유자에게만, 제시 이력은 해당 제시자/질문자에게만 전송한다. 봉투는 진행 중 최종 지목 실패자에게만 전송하며 게임 종료 후 전체 공개한다. 남은 사람의 부분 정답 수는 공개하지 않는다.
- 확인한 카드 이력은 서버에서 복원한다. 직접 쓴 노트는 gameId+playerId별 해당 브라우저 localStorage에 저장하며 다른 게임과 섞지 않는다. 저장 불가 시 화면에 알려준다. 교차 기기 메모 동기화는 미포함이다.
- 공개 타임라인은 최근200개 사건. 확인한 카드 정보는 별도로 보존한다. 새로운 전체 추론/정답 자동 계산은 하지 않는다.
