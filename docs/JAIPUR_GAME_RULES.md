# 자이푸르 기본판과 온라인 진행 정책

2026-09-10. 사용자의 자이푸르 개발 진행 요청에 따라 구현한다. `jaipur-base-v1`을 사용한다. 기존 게임의 TO_BE_CONFIRMED 항목은 변경하지 않는다.

## CONFIRMED — 기본 규칙

근거: [Space Cowboys 영문 설명서](https://cdn.svc.asmodee.net/production-spacecowboys/uploads/2025/11/Rules-JAIPUR-12x17-Version-EN_BD.pdf), [공식 소개](https://www.spacecowboys-games.com/game/jaipur/). 판정 구현은 이 기본판 기준이다.

- 정확히 2인, 인장 2개를 먼저 얻으면 매치 승리.
- 카드 구성: 다이아몬드·금·은 각 6, 천·향신료 각 8, 가죽 10, 낙타 11. 시장에 낙타 3장을 두고 나머지 카드를 섞어 각자 5장, 시장에 2장을 배분한다. 손패의 낙타는 무리로 분리한다.
- 자신의 차례에 상품 1장 획득 / 시장 낙타 전부 획득 / 상품 교환 / 한 종류 판매 중 하나만 한다. 손패는 7장까지이고 낙타는 한도에 포함되지 않는다.
- 교환은 시장 상품 2장 이상과 자기 상품·낙타를 같은 수로 교체한다. 같은 상품을 받으면서 내놓을 수 없다.
- 다이아몬드·금·은은 최소 2장 판매. 상품 토큰은 높은 값부터 받으며, 3·4·5장 이상 판매 시 해당 보너스를 받는다. 상품 토큰이 부족해도 판매 장수를 기준으로 보너스를 받는다.
- 상품 토큰 3종 소진 또는 시장을 5장으로 보충할 수 없으면 즉시 라운드 종료. 덱이 비었다는 사실만으로 종료하지 않는다.
- 낙타가 더 많은 사람은 5점, 같은 수면 아무도 받지 않는다. 점수 동률은 보너스 토큰 수, 상품 토큰 수 순으로 판정한다. 다음 선공은 직전 라운드 패자.

## CONFIRMED — 디지털 정책

개발안의 기본값으로 진행하며, 아래는 공식 규칙에 추가한 온라인 동작이다.

- 대기실은 현재 공통 정책처럼 준비 확인 없이 방장이 시작한다. 라운드 결과 화면의 확인은 대기실 준비와 별개다.
- 턴 제한/자동 패스 없음. 새로고침·연결 끊김은 손패와 차례를 유지한다. 명시적으로 방에서 나가면 매치를 취소하고 승자를 부여하지 않는다.
- 매치 중에는 방 게임 교체가 불가능하다. 각 라운드 결과를 두 사람이 확인하면 새 라운드를 배분한다. 매치 종료 후 기존 `room:selectGame`으로 같은 방에서 다시 시작하거나 다른 게임으로 바꾼다.
- 손패 장수·시장·상품 토큰 가치·보너스 더미 장수·덱 잔량·맨 위 버림패·인장은 공개한다. 상대의 손패·낙타 수·현재 점수·보너스 값과 덱 순서는 숨긴다. 자신의 획득 토큰은 확인할 수 있다. 완료한 라운드의 점수와 낙타 수는 공개한다.
- 공식 동점 기준까지 모두 같으면 해당 라운드는 무승부로 기록하고 인장을 주지 않는다. 다음 선공은 직전 선공의 반대다. 인장 승자가 나올 때까지 이어간다. 이는 명시적 디지털 보완이며 공식 동점 규칙으로 표시하지 않는다.
- 보너스 더미가 소진된 경우 추가 보너스를 만들지 않는다. 남은 상품 토큰만 받는다.
- 종료한 방의 방장이 60초간 오프라인이면 기존 구체 게임 정책과 같이 접속 중인 잔류 참가자에게 방장을 넘긴다. 서버 재시작 복구·관전·AI는 제공하지 않는다.

## 구성 데이터

값의 순서와 개수는 서버의 `games/jaipur/domain/catalog.ts`에서 관리한다. 상품 토큰 38개와 보너스 토큰 18개를 배분 전후 보존한다. 기본 구성 자체는 사실 데이터이며 UI 그림은 원본 스캔을 사용하지 않고 코드로 표현한다.

## TO_BE_CONFIRMED — 후속 범위

선택형 턴 타이머, 장시간 미복귀 시 자동 기권, 관전, 점수 공개 변형은 이번 기본판에 포함하지 않는다.
