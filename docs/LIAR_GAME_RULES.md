# 라이어게임 — LIAR_GAME

CONFIRMED — 2026-09-11 사용자가 앞선 웹 진행·개발 제안에 대해 “개발 진행해줘”라고 승인했다. 아래는 독자적인 온라인 진행 정책 `liar-game-v2`이며 특정 실물 상품의 공식 규칙으로 주장하지 않는다. 기존 게임의 미확정 규칙은 변경하지 않는다.

- 4–8명, 시민 N−1명과 라이어 1명. 서버에서 이번 경기의 라이어 담당 횟수가 적을수록 더 높은 확률로 선정하고, 설명 순서는 별도로 섞는다. 역할이 결과 이력으로 확정되지 않도록 전원에게 0보다 큰 확률을 준다(가중치 = 최다 담당 횟수 − 본인 담당 횟수 + 1).
- 방장은 주제(무작위/음식/동물/장소/물건/직업/취미)와 토론 시간(60/90/120초, 기본 90)을 대기실에서 설정한다. 준비 확인 없이 인원·전원 접속 조건을 만족하면 시작한다.
- 역할 확인 15초. 주제는 모두에게, 제시어는 시민 본인에게만 전달한다. 라이어는 제시어와 정답 별칭을 받지 않는다. 개인 카드는 처음에 가려져 있고 본인이 펼치며, 단계 변경·새로고침 때 다시 가려진다.
- 설명은 순서대로 1회, 각 최대 30초와 40자. 제출하면 즉시 공개하고 다음 사람으로 이동한다. 미제출은 “설명하지 않음”으로 기록한다. 제시어를 직접 말하지 않는 것은 플레이 규칙이며 정답에 따른 입력 거부를 제공하지 않는다(정답 탐색 방지).
- 설명 후 자유 토론. 공개 채팅은 메시지당 200자, 개인당 1초 간격, 최근 100개를 보관한다. 토론 외 채팅은 금지한다. 내장 음성은 제공하지 않는다.
- 비밀 투표 30초. 자신을 제외한 1명을 선택하고 확정한 표는 변경하지 못한다. 전원 제출 또는 마감에 집계하며 미제출은 기권이다. 투표 도중 타인의 제출 여부·대상·중간 집계를 공개하지 않는다.
- 단독 최다 득표자가 시민이면 라이어 승리. 0표면 라이어 승리. 최다 동률이면 해당 후보만 대상으로 30초 재투표를 1회 진행한다(모두 투표권, 자기 투표 금지). 다시 동률 또는 0표면 라이어 승리. 재투표 후보만 공개하고 개별 표는 결과까지 비공개다.
- 라이어가 지목되면 마지막 추측 20초. 라이어만 40자 이내 정답을 1회 제출할 수 있다. 맞히면 라이어 승리, 오답·시간 초과면 시민 승리. NFC 정규화·공백 제거·소문자화를 거친 완전 일치 또는 사전 검수 별칭만 인정한다. AI·부분일치·유사도 판정은 없다.
- 추측 중에는 정답을 공개하지 않는다. 결과에서 제시어, 라이어, 각 투표 회차, 마지막 추측, 승리 이유와 승자를 공개한다. 명시적 이탈은 경기를 취소하며 최종 우승자를 정하지 않는다. 이미 완료한 라운드 점수는 참고용으로 보존하고 진행 중 라운드는 점수를 주지 않는다.
- 일시 연결 끊김은 타이머를 유지하며 동일 자격 증명으로 역할·설명·자기 투표·단계를 복원한다. 진행 중 신규 입장·관전은 없다. 명시적 나가기는 판 취소 및 이탈자 표시 후 공통 대기실 복귀 때 해당 참가자를 제거한다.
- 종료 후 방장이 같은 방에서 재경기하거나 다른 게임으로 교체한다. 라운드 결과 대기 또는 경기 종료 후 방장 연속 오프라인 60초면 연결된 참가자로 승계한다. 서버 재시작 복구는 포함하지 않는다.

## 10라운드 점수제 — CONFIRMED (2026-09-12)

사용자가 중복 출제 방지와 10라운드 점수제 적용을 요청했다. 앞서 제안한 점수·진행 방식을 적용한다.

- 한 경기는 고정 10라운드. 시민 승리 시 시민 각 +1점, 라이어 승리 시 라이어 +3점. 정답 추측 역전도 +3점이며 추가 보너스는 없다.
- 1–9라운드 종료는 `PLAYING / ROUND_RESULT`로 유지한다. 결과·획득 점수·누적 순위를 공개하고 타이머 없이 방장의 `liar:nextRound`를 기다린다. 접속한 방장이 연결 끊긴 참가자를 포함한 기존 명단으로 계속 진행할 수 있다. 오프라인 참가자는 각 단계에서 시간 초과로 처리한다.
- 다음 라운드는 새 역할·설명 순서·제시어·단계 ID를 만들고, 설명·채팅·투표를 초기화한다. 점수와 완료 라운드 이력은 유지한다. 서버에서 gameId·phaseId·방장 권한을 확인한다.
- 10라운드 종료 시 경기 `FINISHED`, 최고 점수 참가자가 최종 우승자이며 동점은 공동 우승이다. 재경기는 점수를 0으로 초기화한다.
- 진행 중 이탈은 경기를 취소한다. 라운드 결과 대기 중 취소해도 이미 지급한 점수를 두 번 지급하거나 지우지 않는다.
