# 라스베이거스 기본판 — CONFIRMED

2026-09-11 사용자가 앞선 기본판 설계 및 온라인 정책 제안에 대해 개발 진행을 승인했다. 오리지널 기본판 규칙과 온라인 편의 정책을 구분한다. 근거: https://www.ultraboardgames.com/las-vegas/game-rules.php 및 공식 규칙 https://www.ravensburger.de/spielanleitungen/ecm/Spielanleitungen/26938_Vegas_EN.pdf (공식 PDF 직접 조회 timeout, 규칙 전재 본문 교차 확인).

- 2–5인, 각자 같은 색 주사위 8개, 카지노 1–6, 4라운드.
- 54장 지폐: 1만/4만/5만 각 6장, 2만/3만 각 8장, 6만/7만/8만/9만 각 5장. 최초에만 서버 난수로 섞는다.
- 카지노 1부터 차례로 합계 5만 이상이 될 때까지 지폐를 앞면으로 배분한다. 지폐를 각각 표시한다.
- 자기 차례에 남은 주사위를 전부 한 번 굴리고, 나온 눈 하나를 골라 그 눈의 주사위 전부를 해당 카지노에 놓는다. 나머지는 다음 자기 차례에 다시 굴린다. 주사위가 없는 참가자는 자동 건너뛴다.
- 전원이 소진하면 카지노별 정산. 양수인 배치 개수가 같은 참가자는 순위와 무관하게 모두 지급에서 제외한다. 남은 참가자에게 개수 내림차순으로 큰 지폐부터 한 장씩 지급. 남는 지폐는 더미 맨 아래로 돌린다. 이번 정산에서 제외된 주사위는 이번 라운드에 다시 쓰지 않는다.
- 다음 라운드에 주사위 8개 회수, 상금 새 배분, 시작 참가자는 입장 순서상 다음 사람. 4라운드 후 총금액 → 지폐 수 → 공동 승리.
- 획득 지폐와 합계는 자기에게만 공개한다. 카지노·배치·남은 주사위·현재 굴린 결과·최근 라운드별 지급 내역은 공개한다. 과거 공개 지급을 기억하거나 계산하는 것은 막지 않는다. 모든 상대 누적 합계는 종료 시 공개한다. 더미 순서는 비공개다.

## 온라인 정책 — CONFIRMED

- 첫 시작 참가자는 서버 무작위(나이 수집 없음), 이후 입장 순서 순환.
- 굴리기와 배치 전체 30초. 굴리기는 gameRevision을 바꾸지만 turnId·deadline은 유지한다. 재접속/재전송으로 다시 굴리거나 시간을 연장하지 않는다.
- 만료 시 아직 안 굴렸으면 서버가 굴리고, 나온 서로 다른 눈 중 균등 무작위 선택하여 전부 배치한다. 자동 처리에도 동일 규칙·보존 검증을 적용한다.
- 일시 disconnect는 타이머 유지. 명시적 퇴장은 CANCELLED. 종료 후 방장 승계·다시 하기·게임 교체는 공통 Room 정책.
- 서버가 정산과 다음 라운드를 원자적으로 처리한다. 연출 완료를 서버 진행 조건으로 삼지 않는다.
- 같은 색의 주사위는 기능상 교환 가능하여 플레이어별 남은 수+카지노별 수=8로 보존한다. 클라이언트는 주사위 수/배치 결과를 제출하지 않는다. 지폐는 액면별 개수와 전체 54장 보존을 검증한다.
