# 티켓 투 라이드 — 미국 구판

2026-09-12 CONFIRMED. 사용자가 개발·일러스트·UI·소리를 승인했고 첨부한 미국 구판 보드와 구성품을 기준으로 한다. 내부 식별자 TRAIN, rulesVersion `train-usa-classic-v1`. 기존 게임의 미확정 규칙은 변경하지 않는다.

## 근거와 구성

- 공식 구판 규칙: https://ncdn0.daysofwonder.com/tickettoride/en/img/tt_rules_2015_en.pdf . 2025년 신판과 혼합하지 않는다.
- 36개 도시, 100개 노선, 30개 목적지. 연결·길이·색은 첨부 보드 및 https://github.com/Rob217/TicketToRideAnalysis/tree/master/data/USA 의 routes.csv와 대조한다. 목적지는 해당 tickets.csv 및 https://www.supercheats.com/ticket-to-ride/wiki/north-america-map-master-routes-list 와 대조했다. 데이터의 도시 이름과 수치는 사실 자료로 사용하며 일러스트는 새로 제작한다.
- 2–5인, 기차 각45개, 열차 카드110장(8색 각12장+기관차14장). 시작 손패4장, 공개 시장5장. 목적지3장을 받고 최소2장 보유한다. 반환한 목적지는 덱 아래에 둔다. 시작 선택은 입장 순서대로 진행하며, 완료 후 서버가 무작위로 정한 선공부터 진행한다(온라인 정책).

## 행동

한 차례에 열차 카드 뽑기, 노선1개 점유, 목적지 뽑기 중 하나.

- 열차 카드는 공개 시장 또는 비공개 덱에서 1장씩 최대2장. 공개 기관차는 첫 선택에서만 가능하고 차례 전체를 사용한다. 비공개 덱의 기관차는 1장으로 센다. 공개 카드를 가져오면 즉시 보충한다. 공개 기관차가3장 이상이면 공개 카드 전부를 버리고 다시 보충한다. 덱 소진 시 버림패를 서버 난수로 섞는다.
- 시장 초기화에 필요한 일반 카드가 부족하면 무한 재추첨하지 않는다. 일반 카드가3장 미만인 극단적 고갈 상태에서는 초기화가 불가능한 시장을 유지한다(디지털 고갈 정책). 일반 카드가 충분한데도 64회 연속 재추첨에 실패하면 남은 일반 카드 중 무작위 3장과 나머지 중 무작위 2장으로 시장을 구성해 종료를 보장한다(온라인 유한 재추첨 정책). 두 번째로 가져올 합법 카드가 전혀 없으면 첫 장으로 턴을 마친다. 소모 가능한 카드가 생기면 정상 초기화 규칙을 다시 적용한다.
- 노선 길이만큼 같은 색 카드와 기관차를 지불하고 기차를 배치한다. 회색은 한 색을 선택한다. 기관차만으로도 지불 가능. 색·노선 점유자·기차 수를 서버가 검증한다. 기존 내 노선과 연결하지 않아도 된다. 2–3인은 복선 한쪽만, 4–5인은 양쪽 사용 가능하나 한 사람이 양쪽을 가질 수 없다.
- 노선 길이1/2/3/4/5/6의 점수는1/2/4/7/10/15.
- 추가 목적지는 최대3장 뽑고 최소1장 보유한다. 남은 카드가3장 미만이면 남은 만큼 받는다. 반환 순서를 직접 지정해 덱 아래에 놓는다. 기존 보유 목적지는 버릴 수 없다. 뽑기 이후에는 취소하거나 다시 뽑을 수 없다.
- 어떤 행동도 불가능하면 서버가 검증한 PASS만 허용한다. 전원이 연속으로 아무 행동도 못하면 STALEMATE로 현재 보드에서 정산한다(디지털 고갈 정책).

## 종료

자기 턴 종료 시 남은 기차가2개 이하가 되면 마지막 순환 시작. 그 플레이어를 포함한 전원에게 정확히1턴씩 추가 제공한다. 이미 시작된 마지막 순환은 다시 초기화하지 않는다.

노선 점수 + 완료 목적지 점수 − 미완료 목적지 점수 + 최장 노선10점. 연속 노선은 도시 재방문과 고리가 가능하지만 같은 노선은 두 번 쓰지 않는다. 최장 동률 모두10점. 총점 동률은 완료 목적지 수, 최장 보너스 보유 순으로 비교하며 그래도 같으면 공동 승리(온라인 잔여 동률 정책).

## 온라인·비공개 정책

- 시간 제한 없음. 접속 단절은 현재 카드 뽑기/목적지 선택 단계와 손패를 보존한다. 명시적 나가기는 CANCELLED로 판을 취소한다. 종료 후 기존60초 방장 승계와 같은 방 게임 교체를 따른다.
- 진행 중 상대의 카드 수·목적지 수·남은 기차·노선 점수는 공개. 카드 색상, 목적지 내용/완료 여부, 덱 순서와 ID는 비공개. 완료 목적지 알림은 본인만 본다. 종료 시 목적지와 정산 내역을 공개한다.
- 모든 실제 카드에는 opaque ID. 공개 목적지 목록의 정적 ticketId와 비공개 인스턴스 cardId를 분리한다. 불법 카드 참조는 존재 여부와 관계없이 동일 오류.
- 같은 방 command는 직렬화. 인증 actor/gameId/turnId/revision/requestId를 검증하고 candidate를 보존 검사한 뒤 단일 commit. 첫 카드 획득도 즉시 commit되며 두 번째 선택과 재접속에서 되돌릴 수 없다.
