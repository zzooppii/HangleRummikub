# 스페이스 크루 핵심 규칙 감사

2026-09-12. 대상은 The Crew: The Quest for Planet Nine 기본판 3–5인이다. 본 문서는 독립 규칙 검토이며 구현 완료 선언이 아니다. 2인 JARVIS와 3인 난도 변형은 대상에서 제외한다.

출처: [Thames & Kosmos 공식 설명서](https://thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf), 인쇄 쪽수 기준. 14–16쪽은 그림까지 확인했다. 로그북의 50개 개별 미션 검토는 별도다.

## 공식 근거에서 확인한 사항

| 영역 | 확인 내용 | 쪽 |
|---|---|---|
| 덱·분배 | 색상별 1–9 네 종류와 로켓 1–4. 3인은 14/13/13장이고 마지막 잔여 한 장은 플레이하지 않는다. | 2, 8 |
| 트릭 | 선도 종류를 보유하면 따라야 한다. 로켓도 선도 종류이며, 일반색 선도에 로켓을 내려면 해당 색이 없어야 한다. 이길 의무는 없다. 완료된 트릭 중 최근 하나만 열람 가능하다. | 3–4 |
| 임무 | 일치 카드가 든 트릭의 승자가 임무 소유자여야 한다. 한 트릭에서 여러 임무가 완료될 수 있다. 잘못된 소유자의 획득은 즉시 실패다. | 10 |
| 순서 | 숫자는 전체 임무의 절대 완료 순번이다. 화살표는 해당 화살표끼리의 상대 순서다. OMEGA는 마지막 임무다. | 14, 16 |
| 동시 완료 | 연속 순서 표식들은 같은 트릭에서 완료 가능하고 카드가 놓인 순서는 무관하다. 그림의 예시는 숫자 1+2와 화살표 >>+>>>이다. | 15 |
| 통신 | 임무 분배 후, 트릭 시작 전에만 시도당 인당 한 번. 색상 카드만 공개하며 최고/유일/최저를 표시한다. 공개 카드는 손패에 포함되고 나중에 상태가 변해도 표식은 이동하지 않는다. | 5–7 |
| 통신 예외 | dead zone에서도 최고/유일/최저 자격은 필요하지만 종류를 표시하지 않는다. disruption N은 N번째 트릭 직전부터 통신 가능하다. | 17 |
| 구조 신호 | 분배 후 최초 통신 전에 결정한다. 전원 동일 방향으로 일반 카드 한 장씩 교환하거나 모두 생략한다. 활성 상태는 미션 재시도 사이에도 유지되며 다음 미션에서 초기화한다. 기록 시도 수는 실제 시도 수에 한 번만 1을 더한다. | 12–13 |
| 5인 양도 | 25번 이후 지정 미션에서 첫 트릭 전 자기 임무 한 개를 다른 사람에게 넘길 수 있다. 27/37번도 허용한다. 임무 총수와 기록 시도 수는 그대로다. | 18–19 |

## 구현 판정에서 분리해야 할 해석

1. **동시 완료의 판정:** 한 트릭의 획득 임무를 어떤 순서로 나열했을 때 모든 절대·상대 제약을 만족할 수 있으면 허용한다. 이는 연속 표식 동시 완료와 마지막 임무의 정의를 함께 적용한 구현 해석이며 모든 조합을 공식 예시에서 직접 보았다는 뜻은 아니다. 실제 50미션의 숫자 표식은 1부터 연속되어 있으므로 `1 + 3 + 무표식`에 2가 빠진 경우는 실패다. 23번의 교환이나 40번의 이동도 숫자2를 제거하지 않는다. `OMEGA + 마지막 남은 다른 임무`는 모두 올바른 소유자가 같은 트릭에서 획득하고 Ω를 마지막으로 배치할 수 있으므로 허용한다. Ω만 단독 트릭으로 획득해야 한다는 추가 규칙은 만들지 않는다.
2. **서로 다른 시간 범위:** `attemptNumber`는 실제 배분 횟수, `distressActive`는 현재 미션의 지속 상태, 기록용 횟수는 성공 후 계산값으로 분리하는 것이 적합하다. 재시도 시 통신권은 회복되지만 구조 신호의 기록 가산은 누적하지 않는다.
3. **서버 계산과 표시:** 완료된 임무 목록을 배열 순서대로 수정하면서 판단하면, 같은 트릭에서 성립하는 연속 임무가 거짓 실패할 수 있다. 트릭 전체를 모아 소유권과 순서 조건을 함께 검증한다.
4. **무채팅 진행:** 5인 양도와 구조 신호의 공동 결정은 정해진 선택·동의 절차로 표현할 수 있다. 임의 손패 정보 입력란은 필요하지 않다. 규칙에 없는 타이머나 자동 찬성은 추가하지 않는다.

## 최소 회귀 사례 제안

| 사례 | 확인할 결과 |
|---|---|
| 숫자 1과 2를 역순으로 플레이해 같은 소유자가 함께 획득 | 두 임무 모두 정상 완료 |
| 첫 화살표가 완료된 뒤 >>와 >>>를 같은 트릭에서 역순 플레이 | 정상 완료 |
| 무표식 임무를 먼저 완료한 뒤 숫자 1 획득 | 순서 위반 실패 |
| 무표식 임무를 먼저 완료한 뒤 첫 화살표 획득 | 그 사실만으로 실패하지 않음 |
| 새 배분을 세 번 하고 한 번 구조 신호 활성, 이후 교환 생략 | 실제 시도 3, 기록 시도 4 |
| 3인 13번째 트릭 후 한 장 잔여 | 14번째 부분 트릭을 생성하지 않음; 미완료 목표는 성공 아님 |
| 공개 최고 카드 외 같은 색 카드들을 모두 사용 | 기존 최고 표식 유지, 통신권 회복 없음 |
| dead zone에서 색상 중간 카드 공개 시도 | 거절, 단순 공개 권한으로 완화하지 않음 |
| disruption 3의 두 번째 트릭 완료 후 | 세 번째 트릭 첫 카드 전 통신 허용 |
| 5인 양도를 한 번 사용한 뒤 두 번째 양도 시도 | 추가 양도 불허 |

이 문서 변경은 코드나 의존성을 변경하지 않는다. 루트 typecheck/test/build는 통합 작업에서 실행할 검증이며, 본 독립 감사에서 실행했다고 주장하지 않는다. PDF 렌더링의 `Invalid Font Weight` 경고는 있었으나 확인한 표식과 본문은 판독 가능했다.

## 2026-09-13 추가 자료 대조

사용자가 제공한 `Crew_Manual_4.7.2020.pdf`의 SHA-256은 `12aded82732014978dfd8a744c6775e75ba9e719b7241e2bab7de42680a8db2f`로 확보한 공식 영문 설명서와 같다. `The_Crew_v_1.0.pdf`는 14쪽짜리 BGG nyfilmfest 번역이며 8–14쪽에 전체 50미션이 있다. 원작 PDF는 저장소에 넣지 않는다.

미션12는 기본 손패 정의만으로 교신 카드까지 교환 대상이라고 추론하면 안 된다. [Birgit Stolte의 저자 확인 전달 답변](https://boardgamegeek.com/thread/2482643/mission-12-and-revealed-cards)(2020-08-12)은 첫 트릭 전 교신을 허용하며, 공개된 교신 카드를 무작위 교환에서 제외하고, 새 카드를 받은 뒤에도 기존 교신 표식을 유지한다고 설명한다. 출처 등급은 저자와 상의했다는 전달 기록이며 출판사 직원의 공식 공지로 부풀리지 않는다. 미션12의 구체 handler는 이 예외를 일반 구조 신호 교환과 분리한다.

필수 추가 회귀: 교신한 카드와 로켓이 모두 있는 손패에서 첫 트릭 후 무작위 교환할 때, 공개 교신 카드는 남고 로켓은 후보에 포함된다. 모든 대상 카드를 이동 전 손패에서 선택한 뒤 동시에 이동하며, 이미 받은 카드를 다시 전달하지 않는다. 교신 표식과 사용 횟수는 유지한다.

## 성공 시점

공식 설명서10쪽의 모든 목표 완료 즉시 종료를 미션17에서도 적용한다. 마지막 완료 트릭까지9가 승리 카드가 아니었고 두 목표가 완료됐다면 즉시 성공한다. 미래의 가상 트릭에서 위반할 가능성은 검사하지 않는다. 48번은 마지막 트릭 조건이 추가되므로 조기 완료로 성공할 수 없다.

목표 카드가 없는 9/13/26/44/46은 요구한 승리 카드 또는 분홍9장 획득을 달성한 트릭 직후 성공한다. 5/16/29/33/34/41/50은 전체 손패 진행을 마친 뒤 성공하며 위반 시 즉시 실패한다. 3인46에서 마지막 남은 한 장이 분홍이면9장을 모두 획득하지 못했으므로 실패한다. 16의 모든9 안전 소진 같은 결과 확정 최적화는 별도 기능으로 추가하지 않는다.
