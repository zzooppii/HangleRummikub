# 스페이스 크루 핵심 규칙 감사

2026-09-12. 대상은 The Crew: The Quest for Planet Nine 기본판 3–5인이다. 본 문서는 독립 규칙 검토이며 구현 완료 선언이 아니다. 2인 JARVIS와 3인 난도 변형은 대상에서 제외한다.

출처: [Thames & Kosmos 공식 설명서](https://thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf), 인쇄 쪽수 기준. 14–16쪽은 그림까지 확인했다. 로그북의 50개 개별 미션 검토는 별도다.

## 공식 근거에서 확인한 사항

| 영역 | 확인 내용 | 쪽 |
|---|---|---|
| 덱·분배 | 색상별 1–9 네 종류와 로켓 1–4. 3인은 14/13/13장이고 마지막 잔여 한 장은 플레이하지 않는다. | 2, 8 |
| 트릭 | 선도 종류를 보유하면 따라야 한다. 로켓도 선도 종류이며, 일반색 선도에 로켓을 내려면 해당 색이 없어야 한다. 이길 의무는 없다. 완료된 트릭 중 최근 하나만 열람 가능하다. | 3–4 |
| 임무 | 일치 카드가 든 트릭의 승자가 임무 소유자여야 한다. 한 트릭에서 여러 임무가 완료될 수 있다. 잘못된 소유자의 획득은 즉시 실패다. | 10 |
| 순서 | 숫자는 전체 임무의 절대 완료 순번이다. 화살표는 해당 화살표끼리의 상대 순서다. OMEGA는 마지막 임무다. | 14, 16 |
| 동시 완료 | 연속 순서 표식들은 같은 트릭에서 완료 가능하고 카드가 놓인 순서는 무관하다. 그림의 예시는 숫자 1+2와 화살표 >>+>>>이다. | 15 |

## 구현 판정에서 분리해야 할 해석

1. **동시 완료의 일반화:** 한 트릭의 획득 임무를 어떤 순서로 나열했을 때 모든 절대·상대 제약을 만족할 수 있으면 허용하는 알고리즘은 연속 표식 예시와 일치한다. 그러나 `1 + 3 + 무표식`, `OMEGA + 마지막 남은 다른 임무`까지 그 알고리즘으로 허용하는 것은 검토자의 일반화다. 설명서에 이 조합을 직접 판정한 예시는 없다. 명시적 공식 답변 없이 확정 사실로 표기하지 않는다.
2. **서로 다른 시간 범위:** `attemptNumber`는 실제 배분 횟수, `distressActive`는 현재 미션의 지속 상태, 기록용 횟수는 성공 후 계산값으로 분리하는 것이 적합하다. 재시도 시 통신권은 회복되지만 구조 신호의 기록 가산은 누적하지 않는다.
3. **서버 계산과 표시:** 완료된 임무 목록을 배열 순서대로 수정하면서 판단하면, 같은 트릭에서 성립하는 연속 임무가 거짓 실패할 수 있다. 트릭 전체를 모아 소유권과 순서 조건을 함께 검증한다.
4. **무채팅 진행:** 5인 양도와 구조 신호의 공동 결정은 정해진 선택·동의 절차로 표현할 수 있다. 임의 손패 정보 입력란은 필요하지 않다. 규칙에 없는 타이머나 자동 찬성은 추가하지 않는다.

## 최소 회귀 사례 제안

| 사례 | 확인할 결과 |
|---|---|
| 숫자 1과 2를 역순으로 플레이해 같은 소유자가 함께 획득 | 두 임무 모두 정상 완료 |
| 첫 화살표가 완료된 뒤 >>와 >>>를 같은 트릭에서 역순 플레이 | 정상 완료 |
| 무표식 임무를 먼저 완료한 뒤 숫자 1 획득 | 순서 위반 실패 |
| 무표식 임무를 먼저 완료한 뒤 첫 화살표 획득 | 그 사실만으로 실패하지 않음 |
| 새 배분을 세 번 하고 한 번 구조 신호 활성, 이후 교환 생략 | 실제 시도 3, 기록 시도 4 |
| 3인 13번째 트릭 후 한 장 잔여 | 14번째 부분 트릭을 생성하지 않음; 미완료 목표는 성공 아님 |

| dead zone에서 색상 중간 카드 공개 시도 | 거절, 단순 공개 권한으로 완화하지 않음 |
