# 할리갈리 — 기본판과 온라인 정책

## CONFIRMED (2026-09-10, 사용자 정정 반영)

사용자 요청: 벨 성공으로 게임을 끝내지 않고, 획득한 카드를 자기 덱 아래에 넣어 상대의 카드가 소진될 때까지 계속한다. `halli-galli-v2`는 이 요청을 기준으로 하며 기존 v1의 2인 최종 벨·15분 제한을 폐기한다.
사용자의 기존 게임 선택 목록에 할리갈리를 추가하는 요청에 따라 아래 기본판과 온라인 MVP 정책을 구현한다. 한글 게임의 미확정 규칙은 변경하지 않는다.

기본 규칙 근거: [AMIGO 공식 다국어 설명서, 영문 9–12쪽](https://blog.amigo-spiele.de/content/ap/rule/01700-ES-AmigoRule.pdf).
2–6명, 카드 56장을 나누고 순서대로 한 장씩 공개한다. 각 더미의 맨 위 카드만 계산하며 같은 과일이 정확히 5개일 때 벨을 누른다. 성공하면 공개 더미 전체를 자기 덱 아래로 가져오고 다음 차례를 시작한다. 오답은 다른 생존자에게 한 장씩 지급한다. 덱이 빈 참가자는 탈락하되 공개 더미는 남는다. 이 프로젝트는 사용자 요청에 따라 두 명이 남아도 계속 진행한다. 2인 오답도 상대에게 한 장을 주며 공개 더미는 그대로 둔다. 마지막 생존자가 승리한다.

### DIGITAL_MVP_POLICY
- 카드 구성은 딸기·바나나·라임·자두 각각 14장: 숫자 1/2/3/4/5의 수량을 5/3/3/2/1로 설정한다. 이 수량표는 위 설명서에 명시되지 않은 구현 정책이다.
- 서버 RandomSource로 56장을 섞어 입장 순서로 배분한다. 첫 참가자부터 시작한다.
- 사용자 속도 개선 요청에 따라 차례마다 있던 1초 관찰 대기를 제거한다. 게임 시작·카드 공개·벨 판정 직후 다음 차례 참가자는 바로 뒤집을 수 있다. 차례별 10초 마감과 서버 자동 뒤집기는 유지하며 벨도 즉시 누를 수 있다.
- 벨은 게임 ID와 현재 gameRevision이 일치할 때만 처리한다. 방의 직렬 실행 순서상 첫 유효 입력만 성공한다. 낡은 화면에서 보낸 입력은 벌점 없이 거절한다. 클라이언트 시각으로 순서를 보정하지 않아 네트워크 지연 차이가 존재한다.
- 오답 벌점이 부족하면 다음 좌석부터 가능한 만큼 지급한다. 오답 뒤에도 새 차례 토큰/10초 마감을 부여한다. 벨 연타는 참가자별 서버 시간 700ms 간격으로 제한한다.
- 마지막 카드를 뒤집은 즉시 탈락한다. 생존자가 정확히 1명이 되었을 때만 정상 종료한다. 마지막 생존자가 남은 공개 더미까지 가져가 56장을 모두 보유하고 승리한다. 2명 상태에서도 정답·오답 벨 이후 남은 덱이 있으면 계속한다.
- 전체 게임 시간 제한은 없다. 차례별 10초 자동 뒤집기만 유지한다. 정상 종료 시 승자는 56장, 다른 참가자는 0장이다. 판 취소 시에는 현재 덱 + 공개 더미 수를 기록하고 승자를 정하지 않는다.
- 명시적 방 나가기는 판 취소, 접속 끊김은 자동 뒤집기로 진행하며 재접속을 허용한다. 결과에서 방장이 같은 방의 대기실로 돌아갈 수 있다.
- 덱 순서/앞면/서버 카드 ID는 비공개다. 참가자별 덱 수·공개 더미 수·맨 위 과일/수·탈락 여부·마지막 판정만 공개한다.
