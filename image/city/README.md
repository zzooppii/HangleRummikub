# CITY 건물 카드 원본 일러스트

30개 건물 template의 원본 PNG를 보관합니다. 생성 원본을 리사이즈하거나 재압축하지 않고 그대로 복사했습니다.

원본 해상도는 모두 1254×1254이며, 이미지 합계는 85,158,128 bytes입니다. 복사 후 SHA-256으로 생성 원본과의 일치를 확인했습니다.

- 파일명: `cb-civ-01.png`처럼 template ID를 소문자로 표기합니다.
- 분류별 6장: `civ` 시정, `gua` 수비, `tra` 교역, `cul` 문화, `lan` 명소.
- 자체 생성된 독립적인 일러스트이며 공식 Citadels 이미지/에셋을 사용하지 않았습니다.
- 각 이미지의 생성 프롬프트와 원본 파일 대응은 [provenance.json](../../apps/web/public/city-art/illustrated-v1/provenance.json)에 기록되어 있습니다.
- 게임은 기존 [512px WebP 배포 이미지](../../apps/web/public/city-art/illustrated-v1/)를 계속 사용합니다. 이 폴더는 원본 보관용이며 앱 번들에 포함하지 않습니다.

카드 이름과 전체 적용 내역은 [카드 비주얼 문서](../../docs/CITY_ROLE_CARD_VISUAL_POLISH.md)를 참고하세요.
