# GEM 보석 카드 원본 일러스트

5개 자원 계열의 원본 PNG를 보관합니다. 생성 원본을 리사이즈하거나 재압축하지 않고 그대로 복사했습니다.

원본 해상도는 모두 1254×1254이며, 이미지 합계는 13,652,971 bytes입니다. 복사 후 SHA-256으로 생성 원본과의 일치를 확인했습니다.

| 파일 | 장면 |
| --- | --- |
| dawn.png | 황금빛 수정 관측소 |
| tide.png | 푸른 수정 동굴과 물레방아 |
| grove.png | 나무뿌리에 둘러싸인 에메랄드 세공소 |
| ember.png | 붉은 보석 용광로 공방 |
| echo.png | 자수정 풍경이 떠 있는 달빛 성소 |

- 자체 생성된 독립적인 일러스트이며 외부 상용 이미지/에셋을 사용하지 않았습니다.
- 45개 카드 각각의 고유 그림이 아니라 5개 자원 계열을 나타내는 그림입니다.
- 생성 프롬프트와 원본 파일 대응은 [provenance.json](../../apps/web/public/gem-art/v1/provenance.json)에 기록되어 있습니다.
- 게임은 [512px WebP 배포 이미지](../../apps/web/public/gem-art/v1/)를 사용합니다. 이 폴더는 원본 보관용이며 앱 번들에 포함하지 않습니다.

적용 내역과 검증 결과는 [GEM UI 개선 문서](../../docs/GEM_CARD_VISUAL_POLISH.md)를 참고하세요.
